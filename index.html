# Academic Risk Intelligence & Intervention Planner ## DWM Mini Project A browser-based data-mining dashboard that explores student records and adds a transparent early-warning support planner. Built with HTML5, CSS3, vanilla JavaScript and Chart.js. ### Main features - Upload a CSV or load the included synthetic sample dataset - Searchable, paginated dataset preview - Missing-value handling, duplicate removal and basic validation - Exploratory statistics and charts - Decision Tree, Gaussian Naive Bayes and Random Forest classifiers - Accuracy, precision, recall, F1 score and confusion matrix - Model comparison and performance-category prediction - K-Means clustering and cluster visualisation - Early-warning risk screening with explainable indicators and tailored support suggestions - Priority list search and CSV export for follow-up planning - Printable analysis report, responsive layout and light/dark theme ### How to run 1. Extract the ZIP. 2. Open `index.html` in Chrome, Edge or another modern browser. 3. Load the sample data or upload a CSV with compatible numeric academic fields. 4. Explore Dataset, Preprocessing, EDA, Models, Comparison, Prediction, K-Means and Risk Planner. No backend, Python, Node.js or React is required. Chart.js is loaded from a CDN, so charts need an internet connection. ### Risk scoring note The risk planner is a transparent rule-based screening aid using available attendance, study-hours, previous-mark, assignment and internal-mark fields. The score is not a trained model or a diagnosis; suggested actions should be reviewed by a teacher or advisor before use. The included dataset is synthetic and intended for demonstration only. ### Dataset fields `student_id, attendance, study_hours, previous_marks, assignment_score, internal_marks, quiz_score, participation, sleep_hours, extracurricular, final_marks, performance`
